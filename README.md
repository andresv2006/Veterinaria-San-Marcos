# Veterinaria San Marcos - Sistema FullStack

Este proyecto corresponde a la **Evaluación Parcial 1** de la asignatura **Desarrollo FullStack II (DSY1104)** en Duoc UC.

## Descripción del Proyecto
Sitio web y plataforma de gestión para la Veterinaria San Marcos ubicada en Rancagua. El sistema permite visualizar información de servicios, noticias, contacto y la administración de la clínica.

## Estructura del Proyecto
- `index.html`: Página principal e información general.
- `nosotros.html`: Historia, propósito y equipo de trabajo.
- `noticias.html`: Publicaciones y novedades.
- `noticia-detalle-1.html`: Detalle de servicio de consulta general.
- `noticia-detalle-2.html`: Detalle de servicio de vacunación.
- `contacto.html`: Formulario de consultas con validaciones JavaScript.
- `confirmacion.html`: Confirmación de envío de formulario.
- `assets/css/estilos.css`: Hoja de estilos global responsive.
- `assets/js/app.js`: Lógica de interactividad y validaciones del sitio.
